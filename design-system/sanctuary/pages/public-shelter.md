# Public Shelter Page

**Overrides Master:** density 7 (virtualized lists), co-brand masthead

## Design Read

Reading this as: redesign-overhaul of a public donor transparency page for visitors and donors, with a trust-first calm field-tool language, leaning toward Soft UI Evolution + Forest palette at higher density for large ledgers.

## Signature

Co-branded sticky masthead: partner logo + org name on the left, Sanctuary mark on the right. Sticky Animals / Money switcher. Attachments and photos open in an in-page highlight lightbox (never navigate away).

## Layout

```
┌──────────────────────────────────────┐
│ [Partner] Org name      [Sanctuary]  │ sticky
├──────────────────────────────────────┤
│ Short trust line · counts            │
├──────────────────────────────────────┤
│ Animals (N)  |  Money (N)            │ sticky tabs
├──────────────────────────────────────┤
│ Virtualized list (animals or ledger) │
└──────────────────────────────────────┘
```

## Rules

- Use Master Forest tokens (not cream/sage).
- Partner logo is primary brand signal; Sanctuary is secondary credit.
- Rows stay dense; photos are thumbs that open the highlight.
- Prefer search/filter over endless scroll chrome.
- No em-dashes in copy.
