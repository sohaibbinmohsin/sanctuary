# Sanctuary

Shelter management PWA for animal rescues and sanctuaries.

## Development

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start Vite dev server
- `npm run build` — type-check and production build
- `npm test` — run Vitest
- `npm run preview` — preview production build

## Environment

Copy `.env.example` to `.env` and fill in values when integrating Supabase, PowerSync, and R2.
